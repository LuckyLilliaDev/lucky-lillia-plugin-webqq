# 图标来源

[icon.svg](icon.svg) 是 QQ 的企鹅图标，取自 [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons/blob/main/svg/qq.svg)。上游是 1200 × 800 的画布，这里只把 `width`、`height`、`viewBox` 改成以企鹅为中心的正方形，路径和颜色原样未动。

上游项目的 Apache-2.0 许可保存在 [LICENSE-dashboard-icons.txt](LICENSE-dashboard-icons.txt)。

QQ 标识及商标归腾讯公司所有，用于标识本插件支持的服务。
